# Real Human Pupil Dataset

The experiments reported in the paper include a real human pupil trajectory dataset collected from human participants.

This dataset is **not publicly released** because it contains human participant data that are subject to privacy protection and institutional research regulations.

To facilitate reproducibility, all experiments performed on this dataset are fully described in the paper, and the complete source code used for training and evaluation is provided in this repository.

Researchers interested in reproducing the experiments are encouraged to use the publicly available Guide Rail dataset included in this repository, which follows the same data preprocessing and experimental pipeline.

If access to the human pupil dataset is required for academic research, please contact the corresponding author to discuss potential research collaboration, subject to institutional approval and data-sharing regulations.
